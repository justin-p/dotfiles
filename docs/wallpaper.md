# Wallpaper assets

Wallpaper image files for manual use in desktop settings.

**Not a stow package.** Flat images at the package root — stowing would incorrectly symlink them into `$HOME`.

## Files

```
wallpaper/
  blue_clouds.png
  dark_leave.jpg
```

## Use

Point your desktop background settings at a file under `~/.dotfiles/wallpaper/`, or copy to a preferred location.

For Bearded Gold theming, see [cosmic-theme.md](cosmic-theme.md) and [boot-theme.md](boot-theme.md) (greeter uses a separate system wallpaper path).
