# Ulauncher

Ulauncher application launcher settings.

## Install (stow)

```bash
cd ~/.dotfiles
stow ulauncher
```

## Main file

`~/.config/ulauncher/settings.json`

- Hotkey: `Ctrl+Super+K`
- Dark theme
- No tray icon or recent apps list

## Gotchas

Extensions are not tracked in this repo — only core launcher settings.
