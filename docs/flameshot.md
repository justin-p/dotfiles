# Flameshot

Flameshot screenshot tool preferences.

## Install (stow)

```bash
cd ~/.dotfiles
stow flameshot
```

## Settings

`~/.config/Dharkael/flameshot.ini`

- Launch at startup
- Tray icon hidden

## Gotchas

Uses the legacy `Dharkael` config path. Newer Flameshot versions may use `org.flameshot.Flameshot` instead.
